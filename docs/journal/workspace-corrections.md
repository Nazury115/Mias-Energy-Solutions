# Reviewing the workspace corrections

Local preview: <http://127.0.0.1:3000>. Sign in with the existing local Owner, Staff or Customer account.

## Documents

1. As Staff, open **Documents**, select a saved draft, edit and save it, then select **Submit for review**. Wait for the submission confirmation. Saving alone leaves it in Draft.
2. As Owner, the Inquiries landing page shows **Document review** with the awaiting-review count and a link to Documents. Open the submitted draft from the queue and preview it.
3. If it says **Business settings await Owner review**, open business and bank settings, check and save them, then return to the document and select **Refresh preview with reviewed settings**. Check the updated preview before approving.
4. Approve and issue, or deny it with a return reason. Staff can edit the returned draft and resubmit. Changing a submitted draft withdraws its submission. Older open approval forms must be reloaded after a change.

Existing saved local drafts are not automatically submitted or issued by this correction. Local documents still use TEST numbers.

## Projects

Open **Publishing**. It includes existing website projects and saved database drafts. Existing fictional examples remain labelled. **Preview project** shows the existing story; **Edit project** creates or reopens a private managed draft at the original URL.

Save edits and use **Preview saved draft**. Only an Owner sees publication and deletion controls. Publication replaces the approved public snapshot; saving edits alone leaves the current public version intact.

**Delete project** requires a reason and confirmation. It removes the public version and moves the draft/photos to **Trash**. **Restore as draft** recovers the editable record but does not publish it. Deleting or unpublishing an existing repository project also suppresses its old source version.

## Mobile view

Open <http://127.0.0.1:3000/dev/mobile?path=%2Fstaff> or select **Mobile preview** in the workspace. Choose a page and phone width, then **Show preview**. Browse or sign in within the frame. It shares the current browser's account; use separate browser profiles/private windows when comparing roles simultaneously.

The helper is available only in development. It does not grant access to protected pages. Use a real phone for the final keyboard, camera and download checks.
